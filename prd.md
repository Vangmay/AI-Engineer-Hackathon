# Crime Scene — Product Requirements Document

**AI Engineer Hackathon · Singapore · May 9, 2026**

---

## Overview

Crime Scene is an AI-generated murder mystery game where every case is unique, procedurally generated in seconds, and experienced entirely through voice and imagery. Players interrogate AI witnesses by speaking to them, examine a crime scene photo, listen to a 911 call, and make their accusation out loud. No two games are the same.

**Tagline:** _Infinite murders. Zero scripts. Every case generated in 8 seconds._

---

## Problem

Every murder mystery game ever made was written by a human. Same cases, same answers, same ending. Once you've played it, it's solved forever. Crime Scene generates infinite unique cases — new victim, new killer, new motive, new clues — every single time.

---

## Core Game Loop

```
Case loads (auto-generated)
        ↓
Crime scene image appears + 911 call plays automatically
        ↓
Player taps a witness face to interrogate by voice
        ↓
Gemini live responds in character, in real time
        ↓
Player interrogates as many witnesses as needed
        ↓
Player speaks their accusation out loud
        ↓
Cinematic reveal — right or wrong, full story explained
        ↓
New case generated on demand
```

## Mystery Generation Engine

Every case is generated by producing the truth first, then building witness stories and clues around it. This ensures internal consistency.

**Generation order:**

1. Generate the truth (hidden from player)
   - Who did it, why, how, when
2. Generate three witnesses from the truth
   - Witness A: honest, knows something relevant
   - Witness B: hiding something unrelated, not the killer
   - Witness C: the killer, lies consistently
3. Generate clues seeded into the crime scene image
   - Two real clues pointing to the truth
   - One red herring
4. Generate the 911 call from Witness A's perspective

## Interface Design

### Philosophy

No dashboards. No reading. The entire game is experienced through audio and one image. The player builds their mental model through conversation, not UI.

### Screens

**1. Case load screen**
Full screen crime scene photo. 911 call plays automatically on load. Three witness faces overlaid as polaroid-style cards in the bottom third. No other UI elements.

**2. Interrogation screen**
Tapping a witness face opens a full-screen voice call interface. Witness avatar, name, role. Live transcript appears as they speak. Single button to end the call and return to the scene.

**3. Accusation screen**
Player holds a button and speaks the name of the killer. A microphone icon pulses. No multiple choice, no list — spoken accusation only.

**4. Reveal screen**
Cinematic sequence. If correct: triumphant audio cue, full story narrated by ElevenLabs voice, timeline reconstructed visually. If wrong: tense audio cue, reveal of the truth, explanation of what the player missed.

## Tech Stack

```
Mystery generation
GPT-5.5 → mystery JSON (truth + witnesses + clues)

Media generation (parallel)
GPT Image 2 → crime scene photo
ElevenLabs → 911 call audio
ElevenLabs → pre-generate witness voice intros
Lyria → ambient score (tense loop)

Runtime
Gemini flash-3.1-live → live witness interrogation
GPT-5.5 → accusation evaluation + reveal narration
ElevenLabs → reveal narration audio

Frontend
React + Vercel → game UI
Convex → session state, case storage, transcript history
```

## Team Split

**Person 2 — Media pipeline**
GPT Image 2 crime scene generation. ElevenLabs 911 call and witness voice pre-generation. Lyria ambient audio integration.

**Person 3 — Frontend**
Crime scene display with witness face overlays. Voice call interface. Reveal sequence animation.

**Person 4 — Voice interrogation**
Gemini flash-3.1-live integration. Witness character system prompt per character. In-persona consistency during live questioning. Accusation detection.

## Minimum Viable Version

If time runs short, ship in this order:

1. Pre-generated case (skip live generation)
2. Working voice interrogation with Gemini live
3. Spoken accusation + text reveal
4. Live case generation
5. Lyria ambient audio
6. Cinematic reveal sequence

The game is playable and impressive at step 3. Everything after is polish.

## Risk Register

| Risk                                               | Likelihood | Mitigation                                                                 |
| -------------------------------------------------- | ---------- | -------------------------------------------------------------------------- |
| Gemini live latency makes witnesses feel unnatural | Medium     | Keep responses capped at 2–3 sentences, add thinking audio cue             |
| GPT Image 2 generates inconsistent crime scenes    | Medium     | Lock scene description tightly in prompt, pre-generate and curate 3 scenes |
| Mystery logic internally inconsistent              | High       | Generate truth first, validate witness stories against it before rendering |
| Lyria API access not confirmed                     | Medium     | Treat as optional — game works without ambient audio                       |
| Too ambitious, nothing works by judging            | Low        | Ship MVP at step 3, add polish after                                       |
